# Ideator OS

**Source of truth** for the Ideator agent system (brief, install notes, prompts, cheat card).

> **You don’t need GitHub to use Ideator.**  
> Friends get a **Grok Bot template link** (one-tap import).  
> This repo is for the maintainer: edit once here instead of copy-pasting across chats.

## What Ideator is

For ideators, inventors, and multi-project makers: an agent that **forges** and stress-tests concepts, **keeps intellectual threads** intact, and — when something is locked — becomes an **ass-kicker** so it ships as a working thing, not another project you “work on.”

**Pain:** Your best ideas never leave the tab.  
**Promise:** Continuity of thought *and* continuity of shipping — same partner, different mode.

3. Send friends the **template link** — not a clone URL.
