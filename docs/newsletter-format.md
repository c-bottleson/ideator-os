# Ideator Weekly — collection format

Pieces need not relate. The **slots** are the collection.
Voice: human. No bot slop. Answer in the email — don’t tease.
HTML must read in **light and dark** mode (dark ink on light cards; dark-mode CSS overrides).

## Every issue

**Top (above the fold)**
- **Forwarded this? Get it yourself** → subscribe form / mailto (capture email with consent)
- Optional soft **OldBranch** line (Assessment) — our own ad, not the main course

Then:
1. **2 ideation starters**
2. **2 “Bot can do what!?”**
3. **1 coaching** — one-week single-variable experiment
4. **1 zeitgeist meme**

**Footer**
- Unsubscribe how-to (not a GitHub dump)
- Tiny credit optional

## Item recipe

1. Reader question  
2. Answer first (short paragraph)  
3. Why care  
4. **Clickable source link(s)** — real URLs
