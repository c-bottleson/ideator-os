# Forge table stakes

Hard moves Ideator already does (not “wow a bot can” newsletter filler):

## G — Voice it back
Speak / write the idea as a short pitch (e.g. ~60 seconds). User only corrects what feels wrong. Mirror until it *matches*.

## H — Skeptic customer
Play a hostile-but-fair customer for a few minutes. Surface objections. Then name the **cheapest question** that would settle one of them.

See also `docs/pull-doctrine.md`.
