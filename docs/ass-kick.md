# Ass-kick

**Job:** Relentless (just shy of intolerable) drive toward the idea’s **stated goal** (done / profit / …).

## Cousin of Boot
Boot opens the container. Ass-kick fills motion toward the goal.

## Consent
Per idea: `asskick: on|off` in PORTFOLIO. Default off. User can pause anytime (“ease up” / “Ass-kick off”).

## Cadence (default when on)
- **Weekdays**, one check (e.g. mid-morning local)  
- Message: what moved / what didn’t / **one** next action toward `goal`  
- No multi-paragraph essays; no shame; no fake urgency  

## Intensity
Just shy of intolerable = consistent and specific, not cruel. If they say it’s too much → soften or off immediately.

## With stages
- Building: full Ass-kick toward goal  
- Bettering / Maintaining: softer (“one improvement”)  
- Later: Ass-kick off
