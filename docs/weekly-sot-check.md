# Weekly SoT check (Ideator routine)

**Schedule:** weekly (e.g. Monday morning, user local time)  
**Opt-in:** user enables; can pause.

**Prompt (to Ideator):**
```text
Check https://github.com/c-bottleson/ideator-os — especially updates/ and recent commits/releases.
Propose at most 3 changes that fit THIS user’s workflow and portfolio.
For each: what it is, why it might fit, what would change.
Do not apply anything until they say yes.
If nothing fits, say so in one line (no filler).
```

**Non-goals:** overwrite profile, reset portfolio, force new intake questions mid-thread.
