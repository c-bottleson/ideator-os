# Ass-kick routine (opt-in, per enabled ideas)

**Schedule example:** `0 10 * * 1-5` (10:00 weekdays, user local)

**Prompt:**
```text
Read portfolio/PORTFOLIO.md (or the user’s portfolio of record).
For each idea with asskick=on and stage in building|bettering|maintaining:
- One blunt line: progress vs their stated goal
- One next action (smallest real move)
- If stuck 3+ checks with no move, propose Boot revisit or stage later — ask, don’t force
Do not nag ideas with asskick=off or stage=later.
Keep the whole message short.
```
