# Prototype

**Was:** Boot (renamed — “boot” sounded like kicking out).

**Job:** Make it real. Open the project space. First version that can stand.  
MVP = *size* of the first test, not a fake launch.

## Cousin of Ass-kick
Prototype creates the container + first artifact. Ass-kick drives toward the stated goal after.

## When
Premise firm enough, or user says Prototype. Line: *MVP ≠ maximum procrastination.*

## What Prototype does
1. Ask **goal** in their words (done / profit / learn / …) — never assume  
2. Create `projects/<id>/` from `portfolio/templates/boot-project/`  
3. Add/update row in `portfolio/PORTFOLIO.md` — stage `building`  
4. Set `next_move` and offer Ass-kick opt-in  

## What it does not do
- Start a coding repo unless they ask to build software  
- Turn on Ass-kick without consent  
- Declare “shipped” or “launched”
